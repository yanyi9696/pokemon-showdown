# 旅程观战开发预览：尚非完整验收版本

本提交独立于玩法稳定性发布候选。不要仅因它位于开发分支末端就默认部署；选取发布目标时应核对交接清单。

目前实现：大厅旅程入口，单人旅程的楼层、队伍公开状态、路线、商店、事件与剧情文字、奖励、祝福、关注选项及公开战斗日志；只读查询、授权检查、缓存、关注节流、重连和结束状态。

尚缺：所有小游戏的完整视觉与操作状态复现、背包编辑及弹窗关注同步、联机旅程、真实玩家和独立观众双端验收、真实多观众网络负载。缓存单元测试的一千次读取不能视为一千名真实观众的容量证明。

服务端采用显式展示字段，不发送账号对象、背包、命令令牌或私有战斗请求。观众不能以目标玩家身份提交动作。新入口遵循既有肉鸽准入规则，不修改登录权限。

本地证据及剩余工作见聚合目录 `playability-stability-20261117/本轮玩法稳定性验收与交接.md`。未操作生产。
