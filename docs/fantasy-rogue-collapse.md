## 档位方向与本地范围

0～5 档取消我方额外六维倍率、通关卡档位倍率，以及高档金币、糖果、碎片加量和商店提前开放。通关卡保留真实捕捉资质与培养成果。护符档原有双方削弱、无局外成长以及通关卡 90% 保留。

1～5 档仍自选 2／4／6／8／10 条，每条最多一次，随开始冒险一并提交并锁定，不增加出发确认。普通账号首次解锁进阶档位前隐藏设置；本地开发预览保持。新局版本为 4；旧战斗版本仍能按其旧词条和面板倍率解析，不向进行中的旧局追加词条。本次按用户要求，在完成验收后备份并重置 Windows 本地 Rogue 进度；不重置登录昵称、认证信息、配置或浏览器数据，不连接生产服务器。

## 适度下调的十条幻想崩坏

| 词条 | 版本 3 → 当前版本 4 | 主要边界 |
| --- | --- | --- |
| 力量增幅 | 直接伤害 +20% → +15% | 普通伤害招式；不改变固定伤害、一击必杀、间接和自损。 |
| 生机充盈 | 保持 HP +15%、一次回复 10% | 受伤后仍活着且严格低于半血；多段后检查，禁疗也消耗机会。 |
| 绝境坚守 | 保留原机制 | 每只每场一次满血致命直接伤害留 1 HP；多段后续可击倒。 |
| 侵蚀抵抗 | 保持外部间接减伤 50% | 自损和主动支付不减免，寄生回复按实际扣血计算。 |
| 净化屏障 | 五回合周期净化 | 每只敌人累计在场第 5、10、15……回合结束时，清除异常、负面附着与负等级。期间状态正常生效，盐腌、寄生种子、幽灵诅咒和持续束缚在净化时移除。换下暂停计数，重返继续；正等级及有利效果保留。 |
| 属性适应 | 保持每层 5%、最多 15% | 普通本体伤害完成后加层，多段整次一次，各属性独立，换人保留。 |
| 环境适应 | 保持不利环境部分削弱 50% | 1.5→1.25、1.3→1.15、0.5→0.75；不改变环境免疫、失败、速度或防御加成。 |
| 强化警戒 | 下一次有效普通攻击 +25% | 不叠加，多段整次消耗；替身消耗，未命中／免疫／固定伤害不消耗，换下解除。 |
| 物价上涨 | +25% → +20% | 原折扣后取整；免费奖励、出售、治疗服务和局外成长不变。 |
| 药效衰减 | 背包 HP 药 -25% → -20% | 先以目标最大 HP 截断原量，再乘 80%；复活、状态／PP 药、中心及战斗内回复不变。 |

不追加“崩坏蓄能”或其他全档共通强化。倍率与现有修正相乘。词条按敌方阵营生效，不占用原特性／道具，不被捕捉、变身或复制带入玩家队伍。换人、变身和同场 Boss 转阶段不刷新一次性次数。

首领前卡片小幅补偿初始资质下调：攻击卡由伤害 +80%／双防 +40% 改为 +90%／+45%；防守卡 +40%／+90% 改为 +45%／+100%；均衡卡按 10 月 26 日调整恢复 +60%／+60%，速度仍 +30%。新增疾风卡为速度 +100%、招式伤害与双防 +30%。这些是原首领支援卡，不是档位全局加成。

## 专属道具与文本审计

专属目录涵盖 itemUser、Mega、requiredItem(s)、形态道具、石板／卡带／存储碟以及幻想霸主所需属性 Z 纯晶。加入对应伙伴且本局尚未获得时，线索事件权重乘 6；最多经过四个符合条件的事件区域必定提供一次线索。搜索成功率起点由 15% 提升至 35%，每等待一层 +2 个百分点、每次失败 +15，最高 85%。仍需完成事件，非直接白送道具；获得一次后停止该道具的加权。普通／幻想卡拉卡拉家族的粗骨头、幻想西狮专属 Z 等纳入检查。变形道具在拍卖中使用正确的道具类型。

修复战斗队伍悬停列表带 `•`、PP、`+` 或 `🔄` 的招式名称翻译，例如 `Powder Snow🔄` 显示 `细雪🔄`。按当前有效图鉴数据核对招式、特性、道具及真实物种的中文覆盖；不把剩余人工演出物种当成肉鸽遭遇。

## 祝福、文本与教程

- 每局一次“更换整批品阶”，可留到后续轮次；只能在本轮尚未领取时使用。整批换成其他品阶组合，已经消耗的单卡刷新次数和本轮排除历史保留。重连不返还。
- 太乐巴戈斯、索财灵、银伴战兽、奈克洛兹玛的固定品阶规则优先，不能使用整批品阶更换。基拉祈保持两个选项/两次领取，比克提尼保持原刷新预算。
- 大数字只在 1、50 层候选池出现，超大数字只在 100、150 层出现。抽取、单张刷新、整批更换及候选池赠送遵守同一门槛。大数字满足自身条件的升级不受出现层数限制。
- 只有明确写作 `【名称】` 的招式/特性才关联悬停与点击说明；普通“免疫”不再被当成免疫特性。未识别的括号内容保持文字，不猜测。提示卡、图鉴和已获得祝福共用渲染。
- 教程版本根据实际内容计算哈希。新老账号在下一局前确认新内容；不会中断进行中的冒险，已确认相同内容不重复弹出。

此前未来视的保存预览、左侧阶段切换回顶、零元购挑战前提醒/确认、潘多拉金提供两个幻想道具及西狮海壬幻想形态专属 Z 修复保留。

## 后续实战记录

`node tools/report-rogue-collapse.js <现有本地数据库路径>` 只读数据库、只输出匿名汇总，按规则版本、档位和组合分开。统计选择率、触发频率、平均回合、战斗胜负与通关；不输出账号名。结算重试去重，资源规则在成功购买/用药事务中计数，不混入每场战斗触发频率。

力量按实际伤害命中，生机按恢复机会消耗，坚守/屏障按消耗，适应按新增层，环境按实际修正，侵蚀按减伤，警戒按整次有效攻击消耗。触发次数不等于收益；多段和群攻可多次计数。通关数除开局数包含未结束的局，不能当成完成局胜率。第五档强制全选，不能据其 100% 选择率判断强弱。首轮仍需按普通/精英/首领以及队伍打法观察伤亡、补给消耗和完整通关表现。
