# 连续对战与专属道具更新验收

本次实现普通区域单场 3～4 只野生宝可梦、野怪禁止换人、训练家公开信息 AI、超梦指挥与最后入场、区域天气／场地、幻想招式教学、专属道具三条获取路线及统一幻想超级进化命名。

## 实际规则

- 普通区域经验在现行规则上增加约 10%，击倒和捕捉均受益；三次战利品抽取合并结算，不重复发放。
- 通常 1% 概率出现第 4 只，梦幻塔灵为 3%，沿用原有概率。捕捉一只后继续下一只，野怪不会主动换人，也不会因折返招式或强制换人道具轮换。
- 训练家使用幻想杯 AI 挑战的决策与推演流程，只读取公开战报和自己的队伍，不读取玩家隐藏配置或未提交行动。
- 200 层前五只守卫可战术换人，幻想超梦在训练家位置指挥；五只全部倒下后进入战场，保留超级进化 X、倒下转为 Y 及未行动时继续行动的机制。
- 普通／精英区域 30% 概率出现适配场景的一种天气或场地，持续 5 回合；已生成环境保存，重试不重抽。
- 幻想教学从 81 层开放，每招 10 幻想碎片，限幻想伙伴自身合法且尚未学会的幻想招式。
- 专属目录覆盖当前数据的 202 件道具。三条路线均按伙伴与道具匹配，已获得的不重复赠送。通用超巨进化许愿星沿用原有渠道，不纳入专属目录。
- 专属遭遇概率随等待楼层、未遇见次数递增；战败后冷却 8 层，可在之后再遇见。战败保留消耗并执行普通遭遇的金币损失，不发胜利奖励。
- 线索调查有 4 个地点，猜错后排除该地点并补充线索，第三次猜错为精英。袭击战败后仍可整理队伍、继续调查；战斗逃跑沿用保留损失的规则。
- 拍卖从 31 层开放，每场 3～5 件拍品。有专属需求时保证其中至少一件匹配道具；另有幻想道具、实用学习机和对战道具。三名对手预算公开且不会超支，可通过施压或激将影响其意愿；落槌才扣款。
- 旧存档当前已生成的分场野战继续按原配置完成，新生成区域使用连续战斗。

## 验证结果

| 检查 | 结果 |
|---|---|
| 完整肉鸽回归 | 2080 项通过 |
| 最后修正后的专项复验 | 75 项通过：连续对战、逃跑、在线房间、200 层流程、经济、新事件交易 |
| 幻想 AI 完整回归 | 287 项通过，含公开信息边界、策略、推演、在线生命周期 |
| 客户端完整测试 | 261 项通过，1 项原有待实现测试 |
| 专属道具数据巡检 | 202 件，前中后期共 606 场原生对战成功初始化，2424 次守卫合法性／捕捉配置检查无错误 |
| 类型与构建 | 服务端、客户端 TypeScript 检查及构建通过 |
| 新增模块代码规范 | ESLint 零错误、零警告 |
| 素材链接 | 新增 9 种训练家头像和超梦指挥像均返回 HTTP 200；修复守墓人无效头像 |
| 本地重启与存档 | 真实 WebSocket 恢复第 60 层、6 人队伍；HP、PP、道具、属性转、金币、背包和局外点数保留；19 份账号数据与重启前备份一致 |

最后专项复验包含专属考验失败不误发奖励、成功不重复发奖、每次线索袭击拥有独立捕捉记录、逃跑重试保持同一记录、拍卖重复请求只扣款一次等边界。

原生对战与 200 层流程为自动化验证，不能当作人工完整游玩或难度评分。浏览器自动批准审核拒绝了本地 `file:` 游戏页面，因此本次未完成浏览器视觉验收，也没有绕过该限制。客户端构建时缺少 PHP 的新闻更新钩子仍是原有非阻断提示，游戏代码构建成功。

拍卖参考发行商 [Modern Art 官方规则](https://www.cmon.com/wp-content/uploads/2023/06/MA_Rulebbok_Artbook_v18-low.pdf) 的轮流加价、预算约束及最高价付款；话术与性格博弈为本作设计。
