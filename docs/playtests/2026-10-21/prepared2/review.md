**幻想杯肉鸽：进化修复、生态图鉴与 200 层测试报告（2026-10-21）**

本次已经完成一局 **200 层通关**。初始伙伴为呆火鳄、水跃鱼，新账号初始 20 点全部用于购买第二个起始名额，六项局外能力加点始终为 0，也没有选择塔灵。测试中通过正常捕捉扩充队伍，正常领取和购买局内养成奖励，没有改存档、发放测试资源、强制判胜、回档重抽或跳过失败结算。

这证明目前存在满足上述条件的通关路线，**不能证明所有开局都稳定可通，也不能从一局推算玩家通关率**。最突出的问题是难度忽高忽低：部分幻想精英仅需 1～3 回合，第 100 层亚莎却造成两次战败，几乎耗尽急救预算。

**本次改动**

| 项目 | 现在的行为 |
| --- | --- |
| 性别进化条件 | 无性别的 `N` 不再被误当成“雄性”；种族本身固定性别，也不再重复列无意义条件。艾路雷朵、雪妖女、蜂女王、焰后蜥等真正分支仍检查性别。 |
| 进化后性别 | 进化到固定性别或无性别种族时同步修正性别，例如雄性土居忍士进化成脱壳忍者后为无性别。 |
| 劈斩司令 | 在队伍进化面板消耗 1 枚**头领凭证**直接进化为仆刀将军，不额外要求击倒次数、携带或新的等级门槛。驹刀小兵到劈斩司令的原等级要求保留。 |
| 头领凭证分类与获取 | 与黑奇石同属“进化道具”；加入对应随机进化道具池，常规商店沿用该类默认设置：第 89 层起、1600 金币。普通道具图鉴与特殊道具说明同步收录。 |
| 头领凭证贴图 | 使用 [PokeAPI 保存的原始道具 PNG](https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/items/leaders-crest.png)，匹配头领凭证外形，游戏运行时读取本地文件。 |
| 生态轮换 | 某生态在路线中**出现**后，后续 5 层不再出现；战斗与精英共用记录，同层两张生态路线也不会相同。记录随存档保存，刷新网页不会重新抽取。 |
| 生态图鉴 | 开始页“幻想杯图鉴”新增**生态区域**，收录 14 个生态可能出现的物种，使用像素小图标；另将稀有乱入与高层精英放入折叠区。目录使用实际生成器的进化分支与等级边界。 |
| 捕捉点亮 | 普通玩家未在该生态捕捉的图标为纯黑剪影，悬停也不泄露名字；成功捕捉后点亮，即使随后放生也保留。在别处捕捉、收礼物、孵蛋不会点亮这里。记录跨局保留。 |
| 本地预览与旧存档 | 本地预览依照现有规则全显示，但不写入真实捕捉记录。旧存档无法追溯原来未保存的捕捉地点，不会凭全局捕捉记录猜测点亮；生态冷却仅恢复旧存档中仍可证实的当前层记录。 |
| 神衣纯洁 | 独立写清低血量双防曲线：满血 ×1、50% HP 时 ×1.5、25% HP 时 ×3、上限 ×6；阈值改为**“每场首次降至50% HP 及以下时”**。 |
| 测试额外发现 | 医疗中心曾把 HP 为 0 的宝可梦蛋计入濒死人数并收取复活费，本次修正。蛋不参与回复收费。 |

头像、战斗画面和已有存档资源没有因本次修改被替换。生态目录延迟生成并缓存静态部分，只在查看图鉴时组装个人捕捉标记；像素图沿用现有图集，不为每只宝可梦加载一张大立绘。

**测试方法与适用范围**

当前浏览器工具因安全策略拒绝读取用户的 `file://` 游戏页面。因此本次采用隔离 SQLite 存档，执行真实游戏指令，并通过原生 `Battle` 引擎逐回合出招、捕捉、消耗和结算。这是**自动策略实战测试，不是逐屏点击的真人试玩**，没有验证手机操作手感、对话阅读节奏、滑雪与钓鱼的实际手感或帧率。

玩家策略按已知玩法进行准备：两只起始核心优先分配糖果；捕捉补属性与队伍短板；学习可用招式、装备所得道具、正常进化与幻想化；商店预留急救资金。只读取玩家自己的请求与公开战报，没有读取敌方未公开配置。普通战斗使用公开信息规则策略，主要首领战使用有时间预算的搜索策略；协同战由原生协同控制器控制盟友和对手。

训练家首领沿用生产搜索策略，单次预算最多 4.5 秒。**固定楼层的野生幻想首领在此脚本也进行了搜索，而现行线上控制器对这些野生首领使用立即决策**，这部分属于附加探测，不能声称与网页服务逐项完全相同。基于时间预算的搜索也使同一随机种子不保证每次得到完全相同的决策。原始每场战报与出招记录保留在本机，可核查本次实际过程。

脚本知道现有祝福文案、对话风格偏好与正常游戏规则，但并非完美玩家。例如支持位培养落后，100 层领取的超级石没有配成合适的应对组合；没有宣称最优解。主测试从初始化到通关没有因脚本维护中断或重新开始。

结果证据见同目录 [campaign-evidence.json](campaign-evidence.json)：**148 场对战、799 回合、23 次实际捕捉、3 次战败**。三次战败分别为第 1 层可尔尼初次切磋、第 100 层亚莎两次；初次切磋失败不会终止奇遇线。第 200 层 19 回合获胜，己方无人倒下，但呆火鳄系核心结束时仅余 29/370 HP，铁臂膀仅余 21/428 HP，仍有资源与轮转压力。

最终队伍为幻想骨纹巨声鳄 Lv.100、幻想巨沼怪 Lv.100、幻想快龙 Lv.100、恶食大王 Lv.100、铁臂膀 Lv.97、幻想洗翠黏美龙 Lv.91。第 200 层入场前，后两只为 Lv.96、Lv.90。整局未进行局外能力加点；结算获得的 23 点留在账号上，没有花掉。局内正常取得的全队成长为双攻 +25%、双防 +27.75%、经验 +5%，两只核心还有各自的少量个人训练。这些是正常游玩取得的局内成长，不等同于局外加点。

另有数局诊断尝试：草／水开局在第 20 层失败、火／水棱彩开局在第 10 层失败、另一组火／水开局在第 30 层失败。较早的脚本还出现过没有读取捕捉控件、错误处理蛋等问题；这些诊断过程不具备统一测试条件，**不合并计算胜率**，也不把脚本缺陷当成游戏难度。正式结论以完整记录的 `run-7-silver` 为准。

最值得优先调整的不是再全面增加经验。当前更像是**支持位落后＋首领类型差异过大**：再次普遍加经验，会让两只核心更早滚雪球，却未必解决替补短板。建议先考虑低等级队员的定向补课奖励、馆主天气／战术的清晰提示，以及单体幻想首领的战术存在感。这里均为建议，本次没有擅自修改相关数值。

选高稀有度祝福还会提高固定首领等级：开局黄金 +5、棱彩 +10。诊断中的棱彩开局面对的是 Lv.18 的第 10 层首领，白银主测试面对 Lv.8。这个代价已经写在系统里，但它对“看到彩色就想选”的心理形成较大阻力。应优先把代价和立即收益放在同一处明确展示，再评估早期代价是否合理；不能只把较高稀有度当成无条件更强。

**区域能否维持新鲜感**

本局实际经过全部 14 个生态。按对战记录计：绿茵森林 8、轻风海岸 11、攀岩峡谷 5、熔岩矿脉 7、废弃电厂 7、幽影墓地 12、极光雪峰 5、郊外小径 9、污泥沼泽 11、迷幻花海 4、天空之柱 5、沙海龙窟 9、旧日遗迹 4、太晶空洞 4 次；战斗与精英合计 101 场。

在可自主选择的 154 次路线中，战斗 69、精英 32、遭遇 7、事件 22、奖励 7、交易 9、奇遇 8。**这些是脚本主动选择后的数量，不能当作系统刷新概率**：为了培养，脚本经常优先选精英；为了剧情，优先选奇遇。其余楼层包含固定首领、休整等，不在这组路线统计中。

事件状态记录涉及 24 个不同事件 ID，含劲敌线和延续事件，不是 24 种完全独立随机事件。实际接触了“我是谁？”、粗点心战争、怪医黑杰克、摘星之志、君莎协助、赌石、旅途同行、传说足迹、旅行的回忆等。可尔尼线按 **1、32、51、65、82、101、122、142 层**经历全部八章，第六章与终章的目标层数基本吻合。

我的判断是：**前中期能维持新鲜感，后期还有重复风险**。五层生态冷却能避免连续刷同一张地图，捕捉点亮让普通战斗附带长期收集目标；分档物种池、高层稀有种与八段劲敌线也确实提供变化。但普通战斗大部分仍是“三只野生伙伴逐个打倒”，精英常常很快结束；若没有需要的新伙伴，其核心操作会重复。奖励区域大多是补给与培养，交易区域多为整理资源，光增加区域名字或宝可梦池不足以长期解决这一点。

更有价值的增量是偶尔让玩家改变一次决策：为特殊进化准备一次修行、在有限球数内选择捕捉目标、用不同属性处理遗迹机关、短回合完成护送或击退目标。现有天气／场地生态已经提供部分差异，可以在此基础上加少量明确目标，避免每次都变成更多杂兵加金币。

**祝福强度、吸引力与改进方向**

本局实际选到的四个白银祝福为：1 层“这才是游击”、50 层“来财，来+”、100 层“事件，爽++”、150 层“效果绝佳，还是效果绝佳”。其余以下为源码效果与本局资源环境的设计评估，**没有逐个用完整 200 层验证，也不是统计排名**。

| 全队开麦 | 构筑型，不宜只看“5%”就判弱 | 6 个已装备声音招式便是 +30%；能跨多只叠加。应直接显示当前全队计数、现在选下去能提升多少。 |
| 耐久转输出 | 特定队伍极强，普通队伍可能负收益 | 与其全面加强，更应在选择前列出当前成员转换后的关键能力差值。能让玩家作出聪明选择，本身就有吸引力。 |
| 艺术就是爆炸 | 小众但有趣 | 爆炸伤害 +50%、自爆不扣亲密度且保留经验，是完整主题；复活成本、幽灵免疫仍限制泛用性。推荐提示与保命／复活资源的搭配，保留它的风险感。 |
| 最终幻想6 | 中后期强，早拿可能难受 | 200 碎片与随机赠送很有价值，但早期赠送可能未进化，主力也暂不能幻想化；固定首领等级代价先兑现。应区分立即可转化的成员与未来潜力。 |

不需要让每个祝福都拥有一套新小游戏。更有效的吸引力通常来自四件事：**立即得到什么、改变哪一种打法、与当前队伍有什么组合、下一个明确目标是什么**。普通数值祝福也可以有清楚用途；需要补强的是没有即时反馈、没有可预期目标、又承担较高代价的那些。

**适合补充的小游戏与经典事件**

以下为设计建议，本次没有新增这些事件。优先建议前三项，以及与特殊进化结合的小修行；它们能补充现有钓鱼、滑雪和剪影问答之外的互动。

| 内容 | 建议玩法 | 适合本项目的理由 |
| --- | --- | --- |
| 树果混合／宝芬制作 | 10～15 秒内按节奏调整搅拌，成功给少量回复、亲密度或树果加工奖励。 | 能把背包树果变成主动选择，避免又发一批经验糖果。宝芬与节奏表演确有原作基础，参考[官方神奥华丽大赛与宝芬介绍](https://diamondpearl.pokemon.com/en-us/trainersguide/supercontests/)。 |
| 狩猎地带 | 限定几颗球，在接近、投诱饵、投球间作选择；带走一只或少量资源即可结束。 | 与生态剪影收集直接相连，让捕捉过程区别于常规打残投球。不要变成付费后纯概率亏损。 |
| 特殊进化修行 | 葱游兵要害训练、惊角鹿招式修行、霜奶仙糖饰舞步等，短事件后保留真实进度。 | 同时修复原作条件和内容新鲜感，玩家有明确理由主动选择事件。 |
| 宝可梦塔／洛托姆机关 | 观察短暂图案，按属性顺序解机关，失败付少量时间或资源，可自行退出。 | 记忆与属性理解交替，触屏也可实现，不必要求精准拖拽。 |
| 宝可梦之笛与拦路卡比兽 | 根据提示完成一小段节拍，或选择其他唤醒办法，随后得到不同互动。 | 经典情境容易理解，成功可导向补给、捕捉或短战斗，避免强迫每次再打同样的敌人。 |
| 百变怪观察站 | 对比动作、属性线索与招式表现，找出伪装者。 | 与已有“我是谁？”剪影问答区分，重点是观察推理，不再做一次名字四选一。 |
| 对战地铁短挑战 | 2～3 场小规则挑战，如有限回复、指定换人目标、保护目标；随时可放弃。 | 面向熟悉玩法的玩家提供短期战术目标，不再复制一条八章劲敌主线。 |
| 华丽大赛小舞台 | 10～20 秒的节奏／招式衔接，按已带招式给不同表现加成。 | 为变化招式、声音招式与喜欢的伙伴提供另一种价值；奖励偏亲密度与选择性素材。 |

小游戏应当短、可退出、失败损失有限。新鲜感来自决策差异，不是让玩家每隔几层完成一次强制反应测试。除少数剧情节点外，不宜让同一长演出反复播放，也不宜用小游戏奖励继续放大两只主力与替补的等级差。
