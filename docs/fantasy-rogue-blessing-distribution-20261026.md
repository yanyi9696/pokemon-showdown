# 幻想杯肉鸽：祝福出现概率与完整分布

核对日期：2026-10-26。依据当前 Windows 开发工作区的实际代码，包含本次“英雄登场、来个好伙计仅第 1 层”的修改。本报告只整理分布，没有调整概率。

## 先看结论

共有 **202 个条目、124 个系列**。白银 **54 个条目／37 个系列**，黄金 **73／47**，棱彩 **75／41**。五号化合物横跨黄金与棱彩，因此分品阶系列数相加为 125，去重后为 124。

大部分无条件祝福在**同品阶、同一次抽取、同等修正**下按系列等概率；仅有楼层限制不会额外加权。不能给每个祝福一个对所有存档都适用的固定百分比：队伍、已经领取的祝福、上一局记录、当前轮已展示内容及塔灵，都会改变候选池和分母。

正常选择发生在开局第 1 层，以及通关第 50、100、150 层后。先确定本轮品阶组合，再对每个卡位先抽系列、后抽该系列的版本。普通情况下是三选一；基拉祈是二选二。

## 2. 系列权重、条件加权与分摊

普通系列基础相对权重为 **100**。只限定第 1 层或第 50 层的祝福仍是 100；满足“必须有某伙伴”的门槛，也不自动比普通系列更高。

- **多版本系列**：属性使者 18 个、如果你是某属性也好 18 个、加时赛 10 个、属性是纽带 18 个、属性进化 18 个，均先合计占一个系列，再在当前有效版本中抽取。五号化合物金／彩分别参加各自品阶池。
- **同行训练家祝福**：通常需一名对应属性伙伴才能入池，权重 100；两名不同伙伴满足对应属性配对时权重 200。单属性系列需两名该属性伙伴；少女乐队需恶＋毒、冬日组合需冰＋地面、看得见的女孩需幽灵＋一般，分别由两名伙伴覆盖。一只双属性伙伴不能独自达成翻倍。龙王同样按龙属性配对。乐园防卫程序没有属性门槛，也没有这项翻倍。
- **就决定是你了**：初始伙伴数为 1／2／3／4／5／6 时，权重分别为 **17／33／50／67／83／100**。旧存档缺少初始标记时回退使用队伍人数。
- **上局结束时记录的同一个祝福 ID**：本局权重乘 **20%**，不是出现概率直接变成 20%。记录取自上局结束时持有、且不是命运附赠的祝福；已经自动升级的祝福按升级后的 ID 记录。其他修正继续相乘并取整，例如双属性配对的同行祝福从 200 降为 40。
- **本轮已展示过同系列**：后续卡位或刷新抽到该系列的权重降为原来的 **15%**；已经展示过的同一个 ID 完全排除，刷新掉的也算。多属性系列仍可能出现另一个版本，但属性进化系列是特别规则：只要本轮出现过任一版本，全系列随后都排除。
- **已领取的同一个 ID**：不会再抽到。不同属性的同系列通常仍可出现；属性转系列和同行系列另有整体互斥。

举例：某白银卡位当前恰有 40 个等权系列，普通单版本祝福为 **2.5%**；一个有 18 个等权版本的系列总计仍是 2.5%，单个版本约 **0.1389%**。若其中某系列翻倍，它变成 **200÷4100≈4.878%**，其余每个是 **100÷4100≈2.439%**。这里 40 只是演示分母，不是所有账号固定有 40 个系列。

精确计算顺序：先按本表条件剔除不合格版本；系列权重由版本的平均出现权重决定，再套本轮同系列 15% 修正；归一化抽系列；系列内部按各版本权重抽取。上局降权只作用于那个 ID，因此同一系列中各版本也可能不等概率。最终某卡位概率还要乘该卡位出现对应品阶的概率；整轮“至少出现一次”要考虑前面抽取后的排除与降权，不能简单把单卡概率乘 3。

**聚集的祈愿**：取得后的紧接下一轮、且未更换队伍时使用祈愿品阶表；只要出现黄金卡位，保证放入 Top Clear Mind（普通祈愿轮为 60% 全金＋10% 混合，即 70% 的轮次有该保证展示机会；基拉祈为 60%）。之后更晚轮次不再提升品阶或保证展示，但队伍条件仍成立时 Top Clear Mind 可进入普通池。固定塔灵和神衣条件可覆盖上述品阶概率。

**斩服少女**：150 层条件成立后，只要有棱彩卡位就保证放入一次，并且该卡不可刷新。无固定塔灵的普通轮次是 32% 全彩＋28% 混合，即 **60%** 的轮次有保证展示机会；基拉祈为 **40%**。同时满足祈愿时，品阶分布按斩服少女规则，黄金卡位仍可保证 Top Clear Mind。

**白银／黄金／棱彩命运**：先正常抽到并领取命运祝福，再从同品阶、非命运、符合条件的系列中**等概率**抽一个，随后该系列有效版本等概率。当前实现不沿用同行翻倍、上局 20% 降权、初始伙伴人数权重，也不排除本轮已经展示但未领取的卡。仍保留已领取、楼层、队伍、互斥等候选条件。不触发 Top Clear Mind／斩服少女的正常卡位保底。Top Clear Mind 的“必须是祈愿之后轮次”检查在普通选择器中；命运赠送只使用候选过滤器，若同轮已经取得祈愿且仍有领取机会（如基拉祈），它可能在同轮被黄金命运赠送。这是当前实现的边界，报告未擅自改动。

**自然升级**：弱冠争满足进化条件转为大器晚成、大数字任务升级为超大数字，不是额外概率抽取。阶段后缀 +／++／+++ 只改变相应奖励档次，不是四份不同权重。

## 4. 刷新如何改变分布

单卡刷新保持品阶，常规每个卡位 1 次，比克提尼 2 次；已展示 ID 不会再出现，同系列按上述规则降权。条件变化造成的旧选项自动修复保留原卡位剩余次数。

整批更换品阶每局一次，必须在本轮领取前使用。它会排除本轮原组合，再按其余组合的原权重重新归一化，保证品阶组合改变。例如常规“三金”改换后：三银 **24/74≈32.4324%**、三彩 **22/74≈29.7297%**、银金彩 **28/74≈37.8378%**。已消耗刷新次数不恢复，本轮展示历史仍保留；固定品阶塔灵不能使用。基拉祈只在三种全同品阶中重抽，不产生混合。

## 6. 目前没有额外加权的典型情况

【凶相】不检查是否已有【威吓】；【林间大合唱】不检查是否已有【虫鸣】；【呃啊种子种子】不检查是否已有【寄生种子】；【愤怒的普通宝可梦】、【谁说我到头了】不按可受益队员数量提高权重。属性使者、属性转、属性纽带也不会因队伍已有该属性自动翻倍。它们都按表内普通权重抽取，领取后是否能充分发挥效果由队伍决定。

因此，“所有无条件祝福大致等概率、阶段限定不加权”与代码基本一致；“满足各种玩法条件都会提高出现概率”目前不成立，主要特例是同行属性配对、就决定是你了的人数权重，以及祈愿／神衣的保证展示机制。命运的二次赠送又使用单独的等概率规则。
