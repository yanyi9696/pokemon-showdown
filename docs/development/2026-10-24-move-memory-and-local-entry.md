# 2026-10-24 技能记忆修复与本地入口核查

开发分支：两个仓库的 `codex/fantasy-rogue`。本轮没有修改正式分支、腾讯云或部署配置；此前 24 个历史 dist 核查与测试记录原样保留。

## 技能池缺失

复现对象包括 40 级【熊徒弟】、【闪电鸟】、【超梦】与【快龙-幻想】。问题不是四个出场招式的数量限制，而是可以替换上场的招式记忆没有补齐。

两条具体路径：

1. 捕捉结算和事件赠送调用 `initializeExperience()`，原先只初始化经验、当前四招和已见招式。高等级加入的伙伴没有补入当前等级以前可学的升级招式。武道家事件的【熊徒弟】经过 `drawBlessingGift()`，存在同一遗漏。
2. `levelMoves()` 原先直接查询普通 `gen9` 图鉴；【快龙-幻想】等形态只存在于 `gen9fantasy`，因此返回空列表，之后升级也无法正常学招。

修复后，幻想形态查询对应普通／地区形态的升级表，并按幻想形态合法技能池过滤。初始化、幻想化和旧冒险读取时补入已达到等级的招式；涵盖队伍、箱子、检查点与待入队捕捉。新的升级招式仍走原来的学习提示，不会被提前标记为已学而跳过提示。

不改变出场四招、等级、HP、状态或道具。已有招式保留剩余 PP，旧存档只有已学记录而没有 PP 时继续按 0 处理；形态存档及临时招式已有 PP 也不退款。未到等级的招式、TM 专属招式与幻想教学招式不因此免费开放。未孵化蛋及波塔拉融合体不套用普通伙伴补齐逻辑。

## 本地界面遗漏的原因

截图打开 `F:\fantasy\pokemon-showdown-client\play.pokemonshowdown.com\testclient.html`，该工作区仍在正式分支 `fantasy`，提交为 `300138e226f01f964a38cbf2fc40c531680ef6c8`。

实际开发客户端是 Git 已登记的工作区 `F:\fantasy\release-audit-20261022\client`，不是冻结副本。此前提交 `b2bd2beeec893cf1007f0a1e6d7bfdc1b68f62ee` 已包含以下功能：

- 初始伙伴默认按世代收起，支持按任一属性筛选。
- 招式按属性筛选；全部、光、射击和接触等分类与自制／增强分类同级，分类内先显示幻想自制或调整过的招式，再显示原版招式。
- 招式详情末尾显示明确的先制度，包括 `+1`、`0` 和负值。
- 学习机按招式实际属性使用本地十八属性光碟 PNG。

没有重写这些已存在的客户端功能，也没有覆盖旧正式分支工作区。统一更新工具仍按配置的开发分支发现最新工作区；成功后新增自动打开本次实际构建的客户端。`-NoOpen` 可用于自动验证；失败构建不会打开客户端，浏览器关联失败也不会把已经核验通过的服务停止。

父目录引导器已备份并补充 `-NoOpen` 转发；本机配置、账号昵称和数据库路径不变。详见 [本地更新工具说明](../local-development-updater.md)。
