# 波塔拉耳环融合立绘

## 当前状态

2026-11-12：用户确认没有授权，暂不接入图库，所有组合视为无融合图，继续由玩家选择原伙伴立绘。实际素材目录为空；没有导入或开放 Pokémon Infinite Fusion 融合图库。现有融合数值、特性、招式与解除规则不变。

有序外观匹配、显式缺图回退、存档及对战／回放链路已作为未启用准备代码保留。不能将这些接口和单元测试表述为“真实融合图库已经实装”；没有后续明确任务与可用素材时，不继续图库导入工作。

官方 [Spriting Guidelines](https://hackmd.io/@PIF-Staff/SpritingGuidelines) 区分基础立绘与融合立绘，明确融合立绘需要许可；[公开项目代码](https://github.com/infinitefusion/infinitefusion-hoenn-public) 不等于全部素材统一授权。待用户提供可用于本项目的素材包及授权范围后导入，不从官网批量抓取或运行时热链。

## 玩家行为

- 第一位为头部，第二位为身体。交换位置重新查询对应组合。
- 同一组合有可用素材时预览融合图，并显示作者和来源；加载成功后方可确认。
- 未收录或图片读取失败／8秒超时时，必须选择第一位或第二位原立绘，不能默默替玩家决定。
- 改换组合、关闭弹窗后，旧加载回调失效；超时后迟到的成功响应也不会覆盖玩家备用选择。
- 融合立绘覆盖队伍详情、战前预览和战斗双方，静态正面图同时用于两侧；当前没有独立背面或闪光变色素材。闪光标记和已有星星动画照常生效。
- 小图标沿用基础伙伴图标，未创建未获授权的融合图标。旧存档的已融合伙伴保留原外观，解除后重新融合才按新图库匹配。
- 精确区分地区形态、Mega、幻想形态等物种 ID，不把未收录的形态套用普通形态融合图。

## 本地素材包格式

`manifest.json` 与 PNG 放同一目录。下面仅为格式示例，作者及许可值必须换为实际记录：

```json
{
  "version": 1,
  "entries": [{
    "head": "Pikachu",
    "body": "Charizard",
    "file": "25.6.png",
    "artist": "作者姓名",
    "source": "https://example.org/实际素材来源",
    "permission": "授权说明或授权文件引用"
  }]
}
```

PIF 文件名按 `头部编号.身体编号.png`（也可有小写备选后缀）；不能假定所有 PIF 编号都等于全国图鉴编号。导入表必须明确填写本项目物种名称，先核实 PIF 编号对应关系。反向组合需另一条记录及另一张图。PNG 96×96 或288×288，不超过2MiB。脚本检查文件结构边界，发布前仍需实际解码和目视确认素材内容与顺序。

先在服务端执行构建，然后以 PowerShell 运行（默认只校验）：

```powershell
node tools/import-rogue-fusion-art.cjs --pack 'F:\素材包\manifest.json' --client-root 'F:\fantasy\release-audit-20261022\client'
```

素材与授权确认后，同命令加 `--write`：写入 `data/fantasy-rogue/fusion-art.ts`、客户端 `sprites/fantasy-rogue/fusions/<头.身-内容hash>.png` 及 `credits.json`。全包先检查再写；不覆盖不同内容的同名图、不允许直接替换已登记组合。变更已有素材需要设计旧标识兼容，保留老资源，不能删除已有存档或回放仍引用的 PNG。输入包与授权原件不一定适合公开，发布清单需单独核查。

完成导入后重新构建两端，按用户授权的发布流程同步发布元数据与图片，并保留旧哈希文件。无需新增依赖、修改认证或数据库表。当前存档仅新增可选 `fusion.sprite`，没有强制迁移；老代码会显示原伙伴立绘，跨版本写回仍须在存档副本验证，不能据此宣称任意版本可安全回退。

## 验证与边界

服务端 `fantasy-rogue-fusion-art.js` 验证顺序、形态隔离、融合／解除、数值不变、协议、幻觉及变身；`fantasy-rogue-fusion-import.js` 用自制透明 PNG 验证导入、幂等、全包先检和路径／元数据拒绝。客户端 `rogue-fusion-art.test.js` 与 `fantasy-rogue.test.js` 验证预览到登场、回放、图片失败、切换组合和关闭异步竞态。测试素材不代表实际融合立绘效果，也不进入正式目录。

服务器只返回当前队伍匹配的目录条目及安全图片标识，不接受玩家提交 URL。公共战斗只发送外观标识，不暴露融合前的隐藏招式、个体值等。资源本地按需请求，首页不加载整套融合图库。
